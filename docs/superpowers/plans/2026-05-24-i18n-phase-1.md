# Plugin I18n Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the first i18n foundation for Suwayomi KOReader plugin UI strings, with a shared translation facade, tests, and a small converted surface area that future phases can follow.

**Architecture:** Phase 1 introduces `suwayomi/i18n.lua` as the only plugin-owned translation boundary. Runtime modules call `I18n.t`, `I18n.f`, `I18n.n`, and `I18n.count` instead of requiring KOReader `gettext` or `ffi/util`. This phase converts shared UI/status modules and plugin shell menus, but leaves feature-controller string sweeps for separate follow-up phases.

**Tech Stack:** LuaJIT / Lua 5.1, KOReader `gettext`, KOReader `ffi/util.template`, Busted specs, Luacheck.

---

## Phase 1 Scope

Phase 1 includes:

- Shared i18n facade: `suwayomi/i18n.lua`
- Facade specs: `spec/suwayomi_i18n_spec.lua`
- Shared UI/status conversion:
  - `suwayomi/ui.lua`
  - `suwayomi/ui/choice_dialogs.lua`
  - `suwayomi/ui/downloads.lua`
  - `suwayomi/ui/list_rows.lua`
  - `suwayomi/downloads/status_formatter.lua`
- Plugin shell menu conversion:
  - `suwayomi/plugin/home.lua`
  - `suwayomi/plugin/settings_controller.lua`
  - `suwayomi/plugin/title_menu.lua`
- Test harness updates for module cache clearing
- Architecture documentation update

Phase 1 excludes:

- User-selectable plugin language setting. KOReader owns active locale.
- `.po` or `.pot` catalog generation.
- Full sweep of all controller/worker messages in Browse, Manga, Chapters, Downloads, Read Sync, and API transport.
- Translating server-provided source names, manga titles, chapter names, scanlators, extension names, and source filter labels.

- [ ] **Step 3: Implement minimal facade**

Create `suwayomi/i18n.lua`:

```lua
-- Boundary: plugin-owned i18n facade.
--
-- Responsibility: wrap KOReader gettext/template helpers behind a stable plugin
-- API for runtime UI strings.
-- Owned state: cached helper functions only.
-- Dependencies: KOReader gettext and ffi/util when present.
-- External data: callers decide which values are user/server data and must not
-- translate them.

local I18n = {}

local cached_gettext
local cached_template

local function identity(text)
    return tostring(text or "")
end

local function fallbackTemplate(text, ...)
    local values = { ... }
    return tostring(text or ""):gsub("%%(%d+)", function(index)
        return tostring(values[tonumber(index)] or "")
    end)
end

local function loadGettext()
    if cached_gettext then
        return cached_gettext
    end
    local ok, gettext = pcall(require, "gettext")
    cached_gettext = ok and type(gettext) == "function" and gettext or identity
    return cached_gettext
end

local function loadTemplate()
    if cached_template then
        return cached_template
    end
    local ok, ffi_util = pcall(require, "ffi/util")
    cached_template = ok
        and type(ffi_util) == "table"
        and type(ffi_util.template) == "function"
        and ffi_util.template
        or fallbackTemplate
    return cached_template
end

function I18n.t(msgid)
    return loadGettext()(msgid)
end

function I18n.f(msgid, ...)
    return loadTemplate()(I18n.t(msgid), ...)
end

function I18n.n(singular_msgid, plural_msgid, count)
    return I18n.t(tonumber(count) == 1 and singular_msgid or plural_msgid)
end

function I18n.count(count, singular_msgid, plural_msgid)
    return loadTemplate()(I18n.n(singular_msgid, plural_msgid, count), count)
end

function I18n.join(parts, separator_msgid)
    local rendered = {}
    for _, part in ipairs(parts or {}) do
        if part ~= nil and part ~= "" then
            table.insert(rendered, tostring(part))
        end
    end
    return table.concat(rendered, I18n.t(separator_msgid or " "))
end

return I18n
```
