# Plugin I18n Phase 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish the Settings and Setup Wizard i18n slice by proving every plugin-authored settings/onboarding label and message routes through `suwayomi/i18n.lua`, while keeping server/user data untranslated.

**Architecture:** Phase 2 builds on the current Phase 1 facade API: `I18n.t`, `I18n.f`, `I18n.n`, `I18n.count`, and `I18n.join`. UI widgets render translated labels, `settings_controller` owns translated setup-flow messages, and `onboarding_connection_worker` returns stable message/error IDs for plugin-authored outcomes instead of preformatted UI text. This keeps subprocess workers free of UI locale policy and keeps raw server/API errors visibly external.

**Tech Stack:** LuaJIT / Lua 5.1, KOReader `gettext`, KOReader `ffi/util.template`, Busted specs, Luacheck.

---

## Phase 2 Scope

Phase 2 includes:

- `suwayomi/plugin/settings_controller.lua`
  - Translate setup/settings controller messages and message IDs.
  - Keep raw subprocess startup errors, API errors, credentials, and paths untranslated.
- `suwayomi/plugin/onboarding_connection_worker.lua`
  - Return stable `message_id` / `error_id` fields for plugin-authored connection outcomes.
  - Keep raw API error strings in `error`.
- `suwayomi/ui.lua`
  - Prove login dialog, onboarding connection dialog, and settings choice dialogs route built-in labels through `suwayomi/i18n.lua`.
  - Remove `_` placeholder variable shadowing from converted i18n file.
- Specs:
  - `spec/suwayomi_plugin_settings_controller_spec.lua`
  - `spec/suwayomi_plugin_onboarding_connection_worker_spec.lua`
  - `spec/suwayomi_ui_spec.lua`
- Docs:
  - `docs/ARCHITECTURE.md`

Phase 2 excludes:

- Full gettext catalog loader changes.
- `.po`, `.pot`, `.mo`, `xgettext`, `msgfmt`, or CI l10n script work.
- Browse, extension, manga, chapters, downloads, read-sync, or API transport string sweeps.
- Plugin-specific language settings.
- Translating server-provided source names, manga titles, chapter names, scanlators, extension names, filesystem paths, URLs, credentials, debug data, or raw API error text.

```lua
local ONBOARDING_RESULT_MESSAGES = {
    connection_test_passed = "Connection test passed.",
    connection_test_passed_after_retry = "Connection test passed after retry.",
}

local ONBOARDING_RESULT_ERRORS = {
    missing_server_url = "Enter a Suwayomi server URL first.",
    could_not_connect = "Could not connect to Suwayomi.",
}

local function translateResultMessage(result)
    local message_id = result and result.message_id
    local msgid = message_id and ONBOARDING_RESULT_MESSAGES[message_id]
    if msgid then
        return I18n.t(msgid)
    end
    return (result and result.message) or I18n.t("Connection test passed.")
end

local function translateResultError(result)
    if result and result.error then
        return result.error
    end
    local error_id = result and result.error_id
    local msgid = error_id and ONBOARDING_RESULT_ERRORS[error_id]
    if msgid then
        return I18n.t(msgid)
    end
    return I18n.t("Could not connect to Suwayomi.")
end
```
