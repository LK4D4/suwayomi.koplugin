# Plugin I18n Phase 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert Browse source discovery and extension management UI text to the plugin i18n facade, including context-aware short labels, while preserving source, extension, manga, and server data as untranslated external content.

**Architecture:** Phase 3 extends `suwayomi/i18n.lua` with context helpers, then routes the Browse controller, source catalog, extension controller, and Browse UI through that facade. Controller specs prove plugin-authored messages are translated; UI specs prove menu labels, prompts, filter state labels, and action labels are translated while external names remain raw.

**Tech Stack:** LuaJIT / Lua 5.1, KOReader `gettext`, KOReader `ffi/util.template`, Busted specs, Luacheck.

---

## Phase 3 Scope

Phase 3 includes:

- `suwayomi/i18n.lua`
  - Add context translation helpers needed by short Browse labels.
- `suwayomi/browse/controller.lua`
  - Translate source fetch loading, timeout, startup failure, and missing-setup messages.
- `suwayomi/browse/source_catalog.lua`
  - Translate source language menus, title-bar actions, source-load failures, and empty-filter feedback.
- `suwayomi/browse/extensions.lua`
  - Translate extension fetch/action lifecycle messages, action status text, search actions, empty search text, and fallback titles.
- `suwayomi/ui/browse.lua`
  - Translate Browse menu titles, extension actions, source mode actions, source search prompt chrome, source-filter state labels, and source-filter action rows.
  - Translate the remaining plugin-authored menu chrome already living in this file: global search prompts/results, pagination actions, manga-menu fallback titles, and library-menu fallback titles.
- Specs:
  - `spec/suwayomi_i18n_spec.lua`
  - `spec/suwayomi_browse_controller_spec.lua`
  - `spec/suwayomi_browse_source_catalog_spec.lua`
  - `spec/suwayomi_browse_extensions_spec.lua`
  - `spec/suwayomi_ui_browse_spec.lua`
- Docs:
  - `docs/ARCHITECTURE.md`

Phase 3 excludes:

- `.po`, `.pot`, `.mo`, extraction scripts, compile scripts, and CI gettext tooling.
- Plugin-specific language settings.
- Full Library, Manga, Chapters, Downloads, Read Sync, API transport, or metadata conversion outside the shared `suwayomi/ui/browse.lua` chrome already touched by this phase.
- Translating Suwayomi source names, extension names, extension package names, source filter names/values, manga titles, chapter names, scanlator names, server URLs, filesystem paths, credentials, raw API errors, or debug log keys.
